Os __requisitos__ definem o que o sistema deve fazer e sob quais restrições, o "o que deve fazer" são  os requisitos funcional e "as restrições" são requisitos não-funcionais. Para exemplificar a diferença entre conceitos será usado o exemplo de um sisteme de um banco onde os  requisitos funcionais são pagar boleto, cancelar cartão, transferência bancaria. já os requisitos não funcionais estão relacionados a desempenho, disponibilidade do sistema. 

A definição de requisitos é essencial para construção de um software. Não adianta ter um ótimo design, usar uma linguagem moderna ou usando o melhor modelo para desenvolvimento  se o software não atende as necessidades dos usuários. Especificar requisitos de forma erronia especialmente no inicio  do projeto leva a um alto custo e retrabalho.
